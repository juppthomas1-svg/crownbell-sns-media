## 5. 自動化の方法（決定事項）
- 投稿は **Metricool**（公式に認められた予約投稿サービス）経由で行う。Claude が直接ログインして投稿するのは規約違反なので**やらない**。パスワードはチャットで受け取らない。
- まずは **Metricool 無料プラン**で試す：月20投稿まで、X は対象外。→ Instagram と TikTok を自動化。
- X は、Typefully（X専用の予約サービス、Claudeと連携あり）か、Claudeが1週間分の文章を作ってオーナーが予約する形。効果が出たら Metricool 有料（Starter 約20ドル＋X 約10ドル/月）に切り替えて X も自動化。
- Claude と Metricool をつなぐのは、claude.ai の「設定 → コネクタ」で「Metricool Social Media Management」を追加。
- つないだ後にやること：
  1. テスト投稿を1本予約して動作確認（動画を自動で出せるかも確認）
  2. 毎週日曜の朝に動く予約タスクを作る：先週の数字を Metricool から読む → 伸びた内容に寄せて1週間分を作る → Metricool に予約 → オーナーにまとめを送る
  3. 予約の一覧と数字を1画面で見られる管理ページ（任意）
- 投稿は数日前に予約されるので、問題があればオーナーが Metricool で消せる。

## 6. 投稿のルール（必ず守る）
- 「国家資格」「公認」「国が認めた」「内定が取れる」「書類選考に通る」「TOEIC○点相当」「CEFR○○相当」など、根拠のない表現は**使わない**（景品表示法）。民間資格であることがわかる書き方にする。
- 合格を約束しない（「資格欄が埋まる」ではなく「埋めにいく」など）。
- 実在しない受験者の体験談・口コミを作らない。他人の動画で一般人のふりをして宣伝しない。お金や無料受験のお礼をして紹介してもらう時は #PR。
- **本番の試験問題（社外秘）と同じ問題・場面は使わない**。クイズは毎回オリジナルで作る。体験版の問題も使わない。
- 実在の企業名・人物名は出さない。
- 言い方は格調高く、安っぽくしない（TOEIC・英検と並ぶ資格を目指している）。「30分で」など手軽さだけを売る言い方は避ける。
- 問題をレビューした講師について書く時は「英語教育の国際資格 Cambridge CELTA と MBA を持つ講師がレビュー」まで。講師の名前は出さない。

## 7. 投稿の形
- 投稿文は「です・ます」、絵文字は控えめ、ハッシュタグ3〜5個（#ビジネス英語 #英語クイズ #就活 #27卒 #28卒 #英語学習 など）。
- 投稿の時間：学生がスマホを見る21〜23時が中心。
- 内容の割合：ビジネス英語クイズ5割／「その英語、失礼かも」2割／就活×英語2割／検定の紹介1割。
- 最後は「無料体験版（約5分）はプロフィールのリンクから」で締める。
- 動画のデザインと作り方は「SNS動画_引き継ぎキット.zip」の はじめに読む_引き継ぎ.md を参照（紺と金の賞状風、1080×1920、音なし→BGMはアプリ内）。

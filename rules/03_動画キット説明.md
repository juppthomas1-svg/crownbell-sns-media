## 2. 投稿ルール
- TikTok：1日2本（平日12:00・21:00／土日10:00・21:00）。Instagram リール・YouTube ショートは1日1本（21:00）
- ネタの割合：1問クイズ5割／「その英語、失礼かも」2割／就活×英語2割／検定の紹介・裏側1割
- 投稿文は「です・ます」、絵文字なし、最後に「国際ビジネス言語認定協会」とハッシュタグ3〜5個
- ハッシュタグ例：#英語クイズ #ビジネス英語 #英語学習 #1日1問ビジネス英語 #ビジネス英語実務検定（就活ネタは #就活 #英語面接 #27卒 #28卒）
- 音楽は TikTok の「商用音楽ライブラリ」の歌詞なしBGMをアプリ内でつける（動画ファイルは音なし）

## 3. 絶対に守ること（法律・信頼）
- 「国家資格」「公認」「国が認めた」「内定が取れる」「TOEIC○点相当」「CEFR○○相当」など、根拠のない表現は使わない（景品表示法）。見た目は格調高く、言葉は正確に
- 実在しない受験者の体験談・口コミを作らない。他人の動画のコメント欄で一般人のふりをして宣伝しない（ステマ規制）。頼んで紹介してもらう場合は #PR
- **本番の問題集（社外秘）と同じ問題・同じ場面は動画に使わない**。クイズは毎回オリジナルで作る
- 実在の企業名・人物名は使わない

## 4. デザイン（完成動画01〜07と同じにする）
- 縦型 1080×1920、16〜20秒、音なし
- 紺のグラデーション背景＋金の二重枠（賞状風）。見出しは明朝体（Noto Serif CJK JP）、本文はゴシック（Noto Sans CJK JP）
- 上：協会ロゴ＋「ビジネス英語実務検定 / BUSINESS ENGLISH CERTIFICATION」＋「公式」
- 下：「国際ビジネス言語認定協会」「24時間オンライン受験」
- 流れ：つかみ（約3秒）→ 本題（クイズは3択＋金色のタイムバーで3・2・1）→ 正解と解説 → 最後にロゴと「あなたのビジネス英語力を、証明しよう。」＋「民間資格です」の注記
- 表紙用に、つかみの文字がはっきり出ている2秒あたりの静止画をPNGで書き出す

## 5. 作り方（Claude 向け）
「作り方」フォルダに、実際に使ったファイルが入っています。
- `videos.json`：動画ごとの中身。場面の種類は hook（つかみ）／quiz（3択クイズ）／ngok（失礼→丁寧）／list（フレーズ3選など）／bullets（箇条書き）／cta（最後の画面）
- `gen3.py`：videos.json から動画ごとの HTML を作る（デザインと動きはここに全部入っている）
- `rec2.js`：Playwright で HTML を1本ずつ録画（1080×1920）。出力された off.json の秒数ぶん頭を切る
- 仕上げ：`ffmpeg -ss <off-0.05> -i 録画.webm -t <長さ+0.3> -c:v libx264 -crf 18 -pix_fmt yuv420p -r 30 -movflags +faststart 出力.mp4`
- 手順：videos.json に新しい動画を追加 → `python3 gen3.py` → `node rec2.js`（同じフォルダに logo-seal.png）→ ffmpeg で mp4 に → 何コマか静止画を書き出して、文字の折り返しや見切れがないか目で確認
- 注意：gen3.py の後半に、01〜07用の見出しの書き換えが入っている。新しい動画では videos.json に最初から完成した文を書けばよい
- 録画は1本ずつ順番に（同時に録ると時間がずれて、最初が真っ暗になる）

# インスタ広告動画 引き継ぎメモ（ビジネス英語実務検定）

「広告動画_引き継ぎ.md を読んで、広告動画を作って」と伝えてください。

## 1. 目的
- インスタの広告（リール／ストーリー）で、日本の大学生・就活生を**無料体験版**に呼ぶ。
- リンク先：https://crownbell-kentei.netlify.app/ig-ad （体験版に直行。広告から来た人数を分けて数える用）

## 2. 形式
- 縦長 1080×1920、15〜20秒くらい、mp4。
- 音なしで書き出し、BGM はインスタの中で付ける。
- 最初の1〜2秒で指を止めてもらえる作りにする。

## 3. 流れ（課題提示 → 解決 → 証拠 → 行動）
1. **課題提示**：「就職活動中の皆さまへ　こんなお悩みはありませんか。」
   - 履歴書の資格欄に、書けるものが少ない
   - 英語の力を、どう示せばよいかわからない
   - エントリーシートの提出までに、取れる資格がほしい
2. **解決**：「そんな方のための、ビジネス英語実務検定。」（仕事で使う英語の力を測る、オンラインの検定）
3. **特長**：実務の場面（メール・会議・電話）から出題／24時間いつでもオンライン受験／3級・2級・1級
4. **証拠**：認定番号つきの合格証（見本）を見せる。最短で受験当日に PDF で発行。
5. **行動**：「まずは、無料体験版から。登録不要・約5分」

## 4. デザイン
- 紺（#0F2A5C 前後）と金（#C9A45C 前後）。賞状のような格調。安っぽくしない。
- 実写の写真を使う（AI っぽい画像は避ける）。写真は紺色に自然に溶け込ませる。
- 協会の印（logo-seal.png）を入れる。
- 今のたたき台（21秒版）の見た目は OK。中身や見せ方はオーナーの希望で直す。

## 5. 必ず守ること
- 「国家資格」「公認」「内定が取れる」「書類選考に通る」「TOEIC○点相当」は使わない（景品表示法）。最後に「国際ビジネス言語認定協会が認定する民間資格です」と入れる。
- 合格や内定を約束しない。
- 「30分で取れる」など、手軽さだけを売る言い方はしない。
- 本番の試験問題・体験版の問題は使わない。
- 実在の企業名・人物名、実在しない受験者の感想は使わない。
- 写真は、無料・商用利用OKのサイト（ぱくたそ・Pexels・Unsplash）でダウンロードしたものだけ使う。Google の画像検索や有料サイトのお試し版は使わない。

## 6. 広告の設定（インスタの「投稿を宣伝」）
- 目的：ウェブサイトへのアクセス
- リンク：https://crownbell-kentei.netlify.app/ig-ad
- 相手：「自分で作成」→ 地域は日本だけ、年齢 18〜24歳（「おすすめ（自動）」はアメリカに配信されたので使わない）
- 予算：1日500円 × 5日で様子を見る
